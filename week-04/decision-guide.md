| AWS Service | Type | Use this when... |
|---|---|---|
| S3 | Object storage | You need to store images, files, or backups. |
| EBS | Block storage | An EC2 instance needs a persistent disk. |
| EFS | File storage | Multiple servers need to share files. |
| RDS | Relational database | You need SQL queries and relational tables. |
| DynamoDB | NoSQL database | You need fast key-based data access at scale. |
