Root is the default user when making an AWS project. It has full control over the entire project and permissions to perform any task in the project. IAM allows you to make user accounts in your project which can be provided specific permissions so it can perform certain tasks without giving the user access to everything. The shared responsibility model explains how AWS is responsible for maintaining the security of the physical infrastructure and the customer is responsible for configuring their project safely. For example AWS maintains the data centers while the customer ensures the correct permissions are provided to users to avoid private resources being made public.
